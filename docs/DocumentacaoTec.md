# Documentação Técnica: Behive Transfer API (v1.1.0)**Status do Projeto:** `Funcional / Entrega de Produção (Fase 1)`  **Empresa:** Behive Tecnologia  **Responsável:** Leonardo---## 1. ObjetivoCentralização e padronização do recebimento de vistorias técnicas através de arquivos compactados (.zip, .rar). O sistema visa garantir a integridade dos dados coletados em campo e a organização automatizada no servidor.## 2. Mudança de Escopo (v1.1.0)Diferente da proposta inicial de processamento individual de imagens, a versão atual foca no **transporte de pacotes fechados**.* **Vantagem:** Reduz drasticamente o *overhead* do servidor.* **Experiência do Usuário:** Simplifica a operação do técnico em campo, que realiza apenas um único upload por vistoria.## 3. Fluxo de DadosO funcionamento do sistema segue as etapas abaixo:1. **Interface:** O técnico utiliza a interface Web (Dropzone) para selecionar ou arrastar o arquivo compactado.2. **Identificação:** O Backend recebe o arquivo e gera um identificador único (**UUID**) que é prefixado ao nome original para evitar sobrescrita de arquivos.3. **Persistência:** O arquivo é persistido integralmente no *storage* local da **Behive Tecnologia** e os metadados são salvos no banco de dados PostgreSQL.---## 4. Endpoints da API### 4.1. Upload de Pacote de VistoriaRealiza o envio do arquivo compactado e vincula ao site correspondente.- **URL:** `POST /api/uploads`- **Formato:** `multipart/form-data`| Campo | Tipo | Descrição || :--- | :--- | :--- || `siteId` | `UUID` | Identificador único do Site no sistema. || `nomeTecnico` | `String` | Nome do profissional responsável pela vistoria. || `fotos` | `File` | Arquivo único compactado (.zip ou .rar). |---## 5. Roadmap (Implementações Futuras)Para as próximas versões do **Behive Transfer**, estão planejadas as seguintes evoluções:* **Auditoria de Imagens:** Módulo de descompactação automática em segundo plano para validar a quantidade e qualidade das fotos.* **Cloud Storage:** Integração com **MinIO** para migração do storage local para nuvem privada S3.* **Dashboard:** Interface administrativa para listagem e download dos pacotes enviados por período ou site.---*Documento atualizado em 29 de Abril de 2026.*
