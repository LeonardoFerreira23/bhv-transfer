Documentação Técnica: Behive TransferAPI (v1.1.0)Status do Projeto: Funcional / Entrega de Produção (Fase 1)Nome da Empresa: Behive TecnologiaObjetivo: Centralização do recebimento de vistorias técnicas através de arquivos compactados(.zip, .rar).1. Mudança de Escopo (v1.1.0)   Diferente da proposta inicial de processamento individual de imagens, a versão atual foca no   transporte de pacotes fechados. Isso reduz o overhead do servidor e simplifica a operação   do técnico em campo.2. Fluxo de Dados   ● O técnico utiliza a interface Web (Dropzone) para selecionar um arquivo compactado.   ● O Backend recebe o arquivo e gera um identificador único (UUID) para evitar sobrescrita   de vistorias com nomes idênticos.   ● O arquivo é persistido integralmente no storage local da Behive Tecnologia.3. Endpoints Atualizados   3.1. Upload de Pacote de Vistoria   POST /api/uploads   Formato: multipart/form-data   ● siteId: UUID do Site.   ● nomeTecnico: Nome do profissional.   ● fotos: Arquivo único (.zip ou .rar).4. Roadmap (Implementações Futuras)   ● Módulo de descompactação automática para auditoria de imagens.   ● Integração com MinIO para storage em nuvem privada.
